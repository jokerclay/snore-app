# 告别沉重 Android Studio：超轻量开发打鼾 App 的方案对比

对于“可能只开发一次”的个人自用工具，安装数 GB 的 Android Studio 和配套 SDK 确实过于臃肿和心智负担沉重。以下是三种极致轻量的替代路径：

---

## 方案对比表

| 方案 | 本地开发环境重量 | 手机端体验 | 锁屏后台能力 | 推荐指数 |
| :--- | :--- | :--- | :--- | :--- |
| **方案 A：GitHub Actions 免环境云打包 (原生 APK)** | **0 MB**（本地零安装任何 SDK / AS） | 原生 App，体积 ~5MB | ✅ 完美锁屏，后台整夜不掉线 | ⭐⭐⭐⭐⭐ **(最推荐)** |
| **方案 B：纯网页 PWA / 床头全黑微光夜钟** | **0 MB**（只需文本编辑器/浏览器） | 免装 App，浏览器打开即用 | ⚠️ 需保持屏幕微光不锁屏（需插电） | ⭐⭐⭐⭐ |
| **方案 C：本地微型 Gradle 命令行编译** | **~250MB**（仅便携 JDK + 命令行工具） | 原生 App | ✅ 完美锁屏 | ⭐⭐⭐ |

---

### 方案 A 详解：本地 0 环境，GitHub Actions 免费云端出 APK (推荐)
- **原理**：我们在本地编写好原生 Kotlin/Android 极简源码，配置一个 `.github/workflows/build-apk.yml`。
- **流程**：代码推送到你个人的 GitHub 私有/公开仓库，GitHub 免费虚拟机（已预装完整 Android SDK）在 2~3 分钟内自动编译好 `snore-app.apk`。
- **好处**：
  1. 你的电脑**不用下载 Android Studio**，不用配任何环境变量。
  2. 手机装上的是真正的**原生 APK**，享受原生麦克风权限和锁屏整夜保活能力。

---

### 方案 B 详解：纯网页 Web Audio (免安装 App，床头插电即用)
- **原理**：用 HTML5 Web Audio API 编写一个单文件网页。
- **操作方式**：晚上睡觉时，手机放在床头插上充电线，用手机 Chrome/Safari 打开网页，开启“夜间黑屏微光模式”（屏幕亮度自动调到最低，全黑背景）。
- **好处**：开发速度极快（今晚就能直接跑起来测试），完全不涉及 APK 签名和编译。
- **限制**：手机不能按电源键黑屏（锁屏后浏览器麦克风会被系统强制暂停），必须插电保持网页前台常亮。
